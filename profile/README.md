# Smart Task Manager

Full-stack task management platform with automatic task prioritization,
employee assignment, and real-time progress tracking.

## Repositories
- [FrontProject](https://github.com/smart-task-manager/FrontProject) – React + TypeScript client
- [server](https://github.com/smart-task-manager/server) – ASP.NET Core Web API (C#, Entity Framework Core, SQL Server)

## Key Features
- Task and subtask management with employee assignment
- Automatic prioritization based on deadlines, priority levels, and workload
- Interactive dashboard with statistics and workload distribution
- Layered architecture with RESTful APIs
